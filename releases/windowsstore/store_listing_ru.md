# Store Listing — Русский

## Русский

### Краткое описание (макс. 100 символов)
Локальный центр счетов: сбор почты, сохранение квитанций в PDF и экспорт проводок для DATEV.

### Подробное описание (макс. 10 000 символов)
UniversalInvoiceMail — это локальное настольное приложение для предпринимателей, малого бизнеса и специалистов, позволяющее в автоматическом режиме собирать входящие счета и квитанции из почтовых ящиков, архивировать их в PDF и готовить бухгалтерские проводки без использования облачных сервисов.

Приложение подключается к стандартным почтовым ящикам по протоколу IMAP или через интерфейс Gmail, находит письма со счетами, загружает вложения, локально конвертирует изображения и документы в стандартные PDF-файлы и формирует бухгалтерские пакеты для экспорта в формате DATEV.

**Ключевые возможности:**

- **Автоматический сбор счетов:** Прямое получение писем через защищенные соединения IMAP (SSL/TLS) или официальный API Gmail.
- **Встроенная конвертация в PDF:** Вложения форматов изображений (PNG, JPG, BMP, TIFF) и документов (DOCX, XLSX, EML, MSG) полностью локально преобразуются в PDF с возможностью поиска.
- **Локальное распознавание текста (OCR):** Анализ отсканированных квитанций с помощью Tesseract и pypdfium2 для автоматического определения сумм, номеров документов и сроков оплаты.
- **Экспорт проводок в формате DATEV:** Создание стандартизированных файлов проводок DATEV (CSV в кодировке cp1252) для планов счетов SKR03 и SKR04 для бухгалтера или налогового консультанта.
- **Интеграция с Диспетчером учетных данных Windows:** Пароли учетных записей хранятся в защищенном системном хранилище, исключая хранение в открытом виде.
- **PWA Mobile Companion:** Экспорт обезличенных сводок (без паролей, токенов и текста писем) для проверки на смартфонах и планшетах через браузер.
- **Структурированный локальный архив:** Надежное хранение оригинальных файлов и готовых PDF-документов в выбранном пользователем каталоге.

**Преимущества UniversalInvoiceMail:**

- **100% конфиденциальность:** Финансовая информация и первичные документы никогда не покидают ваш компьютер.
- **Без подписок и облачных сервисов:** Разовая установка, постоянное локальное использование без ежемесячных платежей.
- **Удобная передача данных в бухгалтерию:** Экономия времени при ежемесячной подготовке отчетов благодаря стандартизированным форматам.
