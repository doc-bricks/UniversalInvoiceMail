## ERLEDIGTE MEILENSTEINE (v1.0 bis v2.3.0)

### v2.3.0 — Redigierte Bundles & Web/PWA Companion (2026-07)
- [x] Schema-Kontrakt `universalinvoicemail-invoicebundle-v1.json` für redigierte Rechnungsbundles.
- [x] Desktop-Export & Reimport mit Hash-Abgleich und Konflikterkennung.
- [x] Web/PWA-Companion (`web_companion/`) für browserbasierte Vorschau, Filterung und Rückexport (Betrag, Status, Notiz).
- [x] Offline-Shell mit Service Worker und PWA-Manifest.
- [x] Accessibility-Härtung (Accessible Names/Descriptions) für alle UI-Aktionen.
- [x] Cross-Platform Source Smoke (`tests/source_platform_smoke.py`) und GitHub Actions CI.

### v2.2.0 — DATEV-Export & Betragsbearbeitung (2026-05)
- [x] DATEV-Buchungsstapel-Export (CSV, cp1252) mit Berater- & Mandanten-Konfiguration.
- [x] Editierbare `Invoice.amount`-Spalte direkt in der GUI.
- [x] IMAP MSN -> UID Umstellung (RFC 3501 §2.3.1.1) & NIL-Guard.
- [x] MIME-Charset-Dekodierung (`get_content_charset`) für ISO-8859-1 / windows-1252 Mails.

### v2.1.0 — Multiformat-Anhänge & Gmail Query Builder (2026-04)
- [x] Automatische PDF-Konvertierung für Bilder (`.png`, `.jpg`), `.xlsx` und `.docx`.
- [x] Legacy Office-Fallback (`.doc`, `.xls`) via LibreOffice/COM.
- [x] Gmail Query Builder im Profil-Dialog für Roh-Suchanfragen.
- [x] IMAP/Gmail `X-GM-RAW` Integration.

### v2.0.0 — Mail-Dateien Import & Security-Härtung (2026-04)
- [x] `.eml` und `.msg` Import & Konvertierung in PDF mit Body/Anhang-Merge.
- [x] HTML-Sanitisierung & Escaping gegen HTML-Injection in PDF-Covern, OCR und Mail-Bodies.
- [x] PySide6-Migration (6.10+).
- [x] Dependency Floor Härtung (`Pillow >= 12.2.0`).

### v1.0.0 – v1.8.1 — Basis-App & Filter-Engine (2026-01 bis 2026-03)
- [x] IMAP & Gmail API Integration.
- [x] Vorkonfigurierte Shop-Profile & Sender/Subject/Body-Filter (muss/darf nicht enthalten).
- [x] Hybrid-Design mit Mail-Header in Body-PDFs.
- [x] Sichere Passwort-Speicherung via Keyring.
- [x] Sicheres Tempfile- & Hash-Dedup-Handling.
